# 古典占星命盤專業排盤與推運系統 (my-astro-app)

這是一個專業級的**古典西洋占星 (Classical Western Astrology)** 排盤與綜合推運分析系統，專為占星分析師、愛好者及開發者設計。本程式不僅基於瑞士星曆表 (Swiss Ephemeris / pyswisseph) 與天體力學進行精確天文運算，更全面支援**古典整宮制 (Whole Sign House)**、**五大核心推運體系**以及現代 AI 深度邏輯解盤框架，將千年中世紀與希臘古典占星智慧與當代科技完美結合。

線上體驗站點：[easyastrology.streamlit.app](https://easyastrology.streamlit.app/)

## 🌟 最新核心升級亮點 (2026 最新版本)

### 1. 🏛️ 全面升級正統古典整宮制 (Whole Sign House, WSH)
- **一星座即一宮 (One Sign = One House)**：徹底重構等宮制缺陷，第一宮精確自上升點所在星座之 0°00' 起算，12 星座完美對應 12 宮位。
- **敏感交角 (Angles) 定位**：上升點 (ASC) 與天頂 (MC) 作為宮位內部的精確力量敏感軸點。
- **純天體地平線日夜盤判定 (Sect)**：依據太陽相對地平線周日視運動弧度，精確判定日間盤 (Diurnal) 或夜間盤 (Nocturnal)，無縫連動行星喜樂與吉凶星配置。

### 2. ⏳ 完備的「六大推運體系 (Six Predictive Systems)」
本系統整合古典與現代預測占星學中最具公信力與精準度的六大推運引擎：
1. **希臘年度小限法 (Annual Profections)**：依實歲年齡推算每年流年主導宮位與年度主星 (Lord of the Year)。
2. **古典波斯法達星限 (Firdaria)**：完整排布日/夜盤生命階段之主運星 (Major Lord) 與副運星 (Minor Lord) 75 年時間表。
3. **希臘黃道釋放法 (Hellenistic Zodiacal Releasing, ZR)**：
   - 依據精神點 (Lot of Spirit) 與福德點 (Lot of Fortune) 精算 L1/L2 黃道釋放週期與守護星年數。
   - 自動標記四正角宮之**高光巔峰期 (Major Peak Periods)**。
   - 精確捕捉釋放回轉之**換宮跳躍 (Losing of the Bond, LB)** 重大職涯與人生轉折點。
4. **現代事件占星太陽弧推運 (Solar Arc Directions, SAD)**：
   - 次限太陽一日一年推進弧度同步推動全盤點位。
   - 嚴格篩選容許度 $\le 1.0^\circ$ 之重大硬相位（合相 0°、四分相 90°、對分相 180°）與事件象徵。
5. **次限推運法 (Secondary Progressions / 一日一年)**：
   - **一日一年天體真實軌道**：實歲 $N$ 歲對應出生後第 $N$ 天之星曆真位置。
   - **次限月亮核心指針 (Progressed Moon)**：約 2.5 年走過一個星座/宮位，精確換算落入本命宮位、距換座剩餘月數與當前心理生活重心。
   - **30 年次限月相八大週期 (Progressed Lunar Phases)**：計算日月角距判定 8 大生命階段（新月播種、蛾眉月萌芽、上弦月突破、盈凸月精進、滿月巔峰、散播月分享、下弦月重組、香脂月休整）。
   - **活躍次限相位**：篩選次限星體對本命星體的緊密相位（月亮 $\le 1.5^\circ$、其他星體 $\le 1.0^\circ$）。
6. **三限推運法 (Tertiary Progressions / 一日一月)**：
   - **熱帶月天體物理常數推進**：地球自轉一日對應一熱帶月（約 27.321582 日），捕捉以「週/月」為尺度的具體生活事件推進。
   - **三限月亮當月焦點 (Tertiary Moon)**：約 2.27 個月（68 天）走過一個宮位，精確倒數換宮剩餘週數與當月現實生活焦點。
   - **2.5 年三限月相循環 (Tertiary Lunar Phases)**：每 29.5 個月經歷一次八大月相循環，洞察短期心理節奏與情緒轉折。
   - **當月活躍三限相位**：篩選持續約 2~4 週之關鍵觸發相位。

### 3. 🎯 三大精準專題深度解析報表 (Thematic Special Reports)
針對實戰諮詢中最核心的三大生活訴求，研發專屬指標提取邏輯與結構化 Prompt 框架：
- 💼 **事業職涯與貴人格局專題 (Career & Status)**：聚焦第 10/6/11 宮、精神點 (Lot of Spirit)、勝利點 (Lot of Victory)、希臘黃道釋放法 (ZR 巔峰期與 LB 跳躍)、次限與三限月亮職涯焦點。
- 💰 **財富資產與偏財投資專題 (Wealth & Assets)**：聚焦第 2/8/4 宮、幸運點 (Lot of Fortune)、必要點 (Lot of Necessity)、金星/木星/土星後天狀態、太陽弧引動與法達財星運勢。
- ❤️ **婚戀桃花與人際關係專題 (Romance & Relationship)**：聚焦第 7/5 宮、愛情點 (Lot of Eros)、金星/月亮/火星相位、古典互容接納與次限/三限感情引動期。

### 4. 👑 Ibn Ezra 全盤總御星 (Almuten Figuris) 與 4 大赫密斯阿拉伯點
- **全盤總御星**：依據 12 世紀猶太古典大師 Abraham Ibn Ezra 與 William Lilly 體系，綜合五大生命發光點（日、月、上升、福德點、產前朔望 Syzygy）之五大多元尊貴（廟旺三分界面）與偶然宮位強弱權重，精算總得分與靈魂天賦排行。
- **4 大希臘赫密斯點 (Hermetic Lots)**：
  - **必要點 (Lot of Necessity)**：命運考驗與逆境突破。
  - **愛情點 (Lot of Eros)**：心靈吸引與親密關係。
  - **勇氣點 (Lot of Courage)**：魄力開拓與冒險精神。
  - **勝利點 (Lot of Victory)**：競爭勝出與事業名望。

### 5. 🌐 歷史日光節約時間 (DST) 動態自動校正
- 自動串接地理經緯度與歷史時區資料庫，針對台灣歷史上 1945~1979 年間實施夏令時間（UTC+9:00 vs 標準時 UTC+8:00）依出生精確日期自動動態判定，徹底消除上升點約 15° 的錯宮誤差。

### 6. 🔮 3+1 延伸性問題引導與對話架構
- 產出報告末尾統一提供 3 個量身定制、以引號標註且可直接複製點選的深度情境問題，外加第 4 項「✍️ 自行輸入問題」引導，提供兼具便捷與自由度的諮詢體驗。

## 🤖 多平台 AI 深度解析整合

本程式內建專為占星學理打造的 **「結構化 AI 深度解析框架」**：
- **支援主流 AI 供應商**：原生支援 **OpenAI**, **Google Gemini**, **Groq**, **OpenRouter** 等模型。
- **本命盤專用 AI 大師框架**：依循第一原理，系統化拆解本命格局、命主星落宮、尊貴得分、宮位連鎖、推運交集與具體決策指南。
- **卜卦盤專用 AI 邏輯框架**：嚴格落實 William Lilly 卜卦原典，嚴格審查時效、第一宮問事者徵象星、所問事項第七/十/四/二宮徵象星、接納互容與月亮最後離相位/次一入相位。
- **架構式防禦表格**：前端全面改採具名鍵值字典映射（Dictionary Rename Mapping）與動態欄位過濾，杜絕長度不匹配錯誤。

## 💻 本地安裝與快速啟動

### 1. 環境需求
- Python 3.11+
- pip 套件管理工具

### 2. 下載與安裝依賴
```bash
# 複製專案
git clone https://github.com/wumoztw/my-astro-app.git
cd my-astro-app

# 建立並啟用虛擬環境
python3 -m venv venv
source venv/bin/activate

# 安裝依賴套件
pip install -r requirements.txt
```

### 3. 運行單元測試
```bash
# 執行全套單元測試 (18/18 tests 全部通過)
python3 -m unittest discover tests
```

### 4. 啟動 Streamlit 網頁服務
```bash
streamlit run app.py
```
啟動後在瀏覽器開啟 `http://localhost:8501` 即可開始排盤！
